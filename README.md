# Cybershield

## Installation & Lancement

### Installation
- Cloner le dépôt
  - Dans un terminal, utiliser `git clone <lien_repo>` depuis le dossier où l'on souhaite l'enregistrer.
 
### Lancement
- Ouvrir le dossier du projet dans un éditeur de code _(tel que VSCode)_
- Installer un outil / une extension permettant de créer un serveur web local, de préférence l'extension **Live Server** sous VSCode
- Effectuer un clic droit sur le fichier `index.html`
  - Choisir "Open with Live Server", ou toute autre option permettant d'ouvrir le projet sur un serveur local
  - Le navigateur par défaut ouvre une page
    - Si la page ouverte est la racine du projet, se mouvoir dans l'arborescence de cette manière : projet_js -> cybershield -> le projet doit s'ouvrir
    - Sinon, le projet est utilisable
